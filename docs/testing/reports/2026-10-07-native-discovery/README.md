# 原生海报墙与搜索选源验收

测试环境：ARM64 redroid Android。使用独立的 `com.fongmi.android.tv.preview` 验证包，没有覆盖正式应用。

**验证环境勘误（2026-10-08）：**此前仅按系统报出的 `ro.product.model=SM_F900F` 将该端点标为“三星真机”。对同一 ADB 端点补查发现 `ro.hardware=redroid`，网络接口为容器 veth，故更正环境归类。下列 Android 集成测试结果与截图仍为实际运行所得，不能作为实体三星硬件验收记录。

## 测试环境中的 TMDB 连接问题

在该测试环境的网络中，原反代和优选域落在同一组不可达的 Cloudflare IP，原有回退无法离开坏线路。新方案仅针对 TMDB，同域保留 URL、Host、SNI 和严格证书校验，有限地尝试标准边缘路由；不切换到其他反代转发密钥，尊重显式 hosts／代理并可独立关闭。这是该环境中的网络观察，不能推广为所有三星设备的故障原因或修复验证。

另修复了懒加载 DoH 首次兑现配置时重复清理路由缓存、间接中断自身 DNS 任务的竞态。它会触发域名规则首次并发加载失败。真正修改网络配置仍会失效旧缓存。

最终冷启动测试成功返回非空列表、影片详情和实际图片。结果只保留状态、数量和耗时，不公开反代地址、密钥、设备备份或个人观看记录。
