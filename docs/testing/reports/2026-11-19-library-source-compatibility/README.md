## 修复

- 缺少类型、年份或只有数字集名时，保留已有播放列表。完整日期可能描述入库或资源版本，不据此硬拒同名资源；纯四位年份及标题中的明确年份仍用于区分作品。
- 瓜子同一集两次详情的参数确实变化。原 URL 在旧选择方法中失配，新方法可按同线路唯一原名恢复；播放器一次消费独立复制的详情，避免重复请求改写已选参数，并保留续播进度。
- 识别 `.mp4【S01/4k】`、`.mp4【…全46集】` 等文件名装饰，目录总数不覆盖文件集号，父目录范围不污染单集；真实合集、范围、预告和季号冲突仍保留。
- 多多同一首集的4K／1080p均有明确坐标。相同版本和语言轨的明确画质并列可选唯一最高画质；保存的 URL、原名和版本优先，未知画质或最高画质仍有多个文件时保留原始选择。
