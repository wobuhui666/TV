# 原生海报墙、搜索过滤与海报选源

适用于 TV（leanback）界面。全部采用 Android 原生界面，遥控器和触摸均可操作。现有片源、播放引擎、字幕、收藏和观看记录继续沿用。

## 开启与恢复

进入 **设置 → 首页与发现**：

| 选项 | 默认 | 开启后的行为 |
| --- | --- | --- |
| 首页海报墙 | 原有首页 | 改为推荐海报墙：主视觉、精选／电影／剧集／高分分类、继续观看和横向海报列表。返回首页立即生效。 |
| 搜索相关性 | 原有匹配 | 可选“过滤无关结果”或“严格片名匹配”。搜索结果页顶部也能切换。 |
| 海报详情内选源 | 关闭 | 从首页或推荐页进入海报详情后，直接在详情侧栏选择播放来源。 |
| 海报智能匹配 | 关闭 | 海报选源时补查原名，并按片名、别名、年份和季数的匹配程度排列候选。需要同时开启详情内选源。 |
| 播放来源优先级 | 原有顺序 | 为当前配置指定多个常用来源，按所设顺序优先查询和展示；其余可搜索来源继续补充结果。需要开启详情内选源。 |
| 继续观看卡片菜单 | 关闭 | 首页和完整历史页的卡片长按／菜单键打开原生操作菜单，直接继续观看、找其他来源或删除这一条。 |
| 首页我的片单 | 关闭 | 开启海报首页后可独立打开，展示当前配置的点播收藏和全局发现收藏，直接进入原有详情页。 |
| 海报主视觉轮播 | 原有轮播 | 可选“聚焦时暂停”或“仅手动切换”；各模式都保留左右键切换。适用于海报首页和推荐页的主视觉。 |

**恢复原有浏览体验**会关闭海报墙、详情选源、智能匹配、继续观看卡片菜单和首页片单，把搜索与主视觉轮播切回原有模式，并清除当前配置的播放来源优先级。不会删除片源、历史、收藏、其他配置的优先级或其他设置。这些选项可分别调整；只想过滤搜索，无需换首页。

## 搜索过滤怎么选

- **原有匹配**保留改版前的匹配行为，并非无限制显示网站返回的全部结果。
- **过滤无关结果**排除仅命中部分短词的噪声和明确年份／季数冲突，保留同系列、片名包含关系与明确别名。
- **严格片名匹配**要求规范化后的完整片名及季／续集编号一致；不会把《Rocky II》当成《Rocky》，也不会把《Matrix》末尾的 `x` 当季数。

繁简体、大小写、常见标点、清晰度后缀和标题中的明确别名会规范化。不会因为简介、演员表中出现搜索词就把一部无关作品判为相关。预告、花絮、解说不确认为正片。来源缺少年份时仍可能显示，需结合名称和季数核对。

切换档位会立即重新筛选本轮已返回的结果，无需重新请求片源。无结果时可切回原有匹配或修改关键词；页面会显示已过滤数量。

## 从海报选源播放

1. 打开首页海报墙，或进入原来的推荐页，选择一张海报。
2. 在详情页点 **选择来源**；开启智能匹配时按钮显示 **智能匹配**。
3. 侧栏只收完整片名或明确别名吻合的来源，逐步显示片源名称、实际片名、年份／更新信息与匹配提示。影评、预告与仅提到片名的相关视频留在完整搜索中。可切换 **按源顺序／匹配优先**，多季剧可选季数。
4. 点一个来源，进入现有播放详情和选集流程。匹配不触发自动播放，也不表示已验证该来源一定能播放。

明确的电影／电视剧类型冲突会被排除；缺类型的结果保留供手动核对。选季时会补查含季数的名称，保留基础片名检索作为兜底；智能模式还会利用元数据中的原名。剧集的首播年不作为所有后续季的年份，以免把后续季误排除。豆瓣详情可先显示和选源，TMDB 补充失败不会阻塞这条路径。

来源查询与普通搜索共享最多六个实际任务槽位，本轮最长 30 秒；最多保留 120 个候选。已经移动到某个来源上时，新结果不会把焦点下的卡片移走。**重新查找**开始新一轮；**完整搜索**可手动改片名；返回键先收起侧栏，再返回海报墙。收起、离开页面会取消排队任务和内置 HTTP 请求。不响应中断的第三方插件仍受原来的实际并发上限约束。

## 指定常用播放来源的优先级

1. 在 **设置 → 首页与发现 → 播放来源优先级** 打开编辑器；也可以从海报详情的选源侧栏点 **来源优先级**。
2. 点 **添加来源**，勾选常用来源，再点 **添加所选**。只能添加当前配置中可搜索的来源。
3. 用每行的 **前移／后移** 调整先后，第一项优先级最高；**移除**只取消该来源的优先级。触摸和遥控器均可操作。
4. 点 **保存**后生效；从选源侧栏保存会立即重新查询。**取消**或返回不会保存草稿。

例如设为“来源 B → 来源 A”：会优先安排 B、A 的片名查询；开启智能匹配时，它们的原名查询也优先安排。结果中 B 排在 A 前面，其他来源仍可提供兜底。请求并发执行，晚返回的优先来源仍可进入前列；遥控器停在结果卡片上时先保持位置，移到侧栏控制按钮后再应用新顺序。优先来源会显示“优先 1”等标记。

明确指定的来源顺序优先于智能匹配排序，同一来源内继续按所选匹配模式排序。片名、电影年份、季数和明确类型的冲突仍会过滤，来源优先不会把无关剧集变成匹配项。某个常用来源失败、没有本片或只返回错误版本时，可继续选其他来源；最后仍由你点选播放，不会自动开播。

顺序按配置分别保存，换回同一配置会取回自己的设置。尚未加载或不可搜索的来源会跳过，单纯重载配置不会清空已存顺序。想单独撤销优先级，点 **恢复默认顺序 → 保存**，即可恢复原来的查询与结果顺序；也可以使用上面的 **恢复原有浏览体验**。

## 海报墙操作

顶部导航继续提供搜索、片库、历史／收藏、推荐和设置入口。主视觉左右切换，向下进入分类和海报棚，确认进入详情。继续观看保持原来的续播记录。没有配置播放源时也能浏览推荐，播放前再配置来源。

豆瓣与 TMDB 独立加载；某个服务失败时保留其他已加载内容。首页本轮加载最长 24 秒，失败后可从页面末尾重试，也可继续使用顶部入口。推荐数据只是选片信息，实际播放仍来自自己配置的片源。

### 继续观看卡片菜单

开启后，短按卡片仍继续播放；长按确认键或按遥控器菜单键，会看到片名、集数、已播时间与来源。菜单默认停在“继续观看”，也可选择“查找其他来源”或“删除这一条”。查找来源不会清除原来的观看记录；关闭菜单会回到原卡片，删除后移动到邻近卡片，删空时仍可回到页面导航。

删除始终针对打开菜单时的那一条记录和配置。菜单打开后切换配置、列表刷新或长按松键，都不会把操作变成清空历史。关闭这个选项后恢复原来的长按交互。

### 首页我的片单

在“首页海报墙”打开后，设置中会显示“首页我的片单”。它复用现有收藏：本配置的点播收藏与全局的发现收藏，按最近收藏排序，首页最多显示 20 项，更多内容进入“查看全部”。点一张海报直接进入它原有的点播或发现详情。

片单从本地读取，离线也可显示；收藏、取消收藏后返回首页会刷新。读取失败时保留同配置已显示的片单并提供重试；切换配置不会留下上一配置的收藏供误点。关闭此行只隐藏展示，不会取消收藏。

### 主视觉轮播

- **原有轮播**：保持原来的七秒自动切换。
- **聚焦时暂停**：遥控器停在主视觉卡片上时保持当前影片，移开后重新计时。
- **仅手动切换**：只用左右键选片，不自动切换。

打开菜单、进入后台或离开页面时会停止计时；返回后只安排一次新的轮播。片名和确认目标同步更新，图片加载慢或失败也不会让确认操作进入另一部影片。

## TMDB 网络兼容

在 ARM64 redroid Android 测试环境的网络中，自定义反代域和优选域都解析到同一组不可达的 Cloudflare IP，出现 TCP 超时；另一默认反代出现 TLS 连接重置。保持原反代域名与严格证书校验，使用可达的标准 Cloudflare 边缘后，该环境中的请求返回 HTTP 200。

**验证环境勘误（2026-10-08）：**此前仅按系统报出的 `ro.product.model=SM-F900F` 将该端点标为“三星真机”。对同一 ADB 端点补查发现 `ro.hardware=redroid`，网络接口为容器 veth，应归类为 redroid Android 测试环境。这些网络现象和修复结果仅描述该环境，不能推广为实体三星设备的兼容性结论。

**设置 → 来源 → TMDB 网络兼容**默认开启，也可单独关闭。仅在 TMDB 元数据／图片的原路失败，且 DNS 结果确认为 Cloudflare 网段时尝试有限的边缘路由；保留原 URL、Host、SNI 与证书校验，不切换到另一家反代，不把 API key 发送给其他域名。显式 hosts 与代理设置优先。成功路线短期缓存，失效后回到正常路由。

同时修复首次兑现 DoH 设置时重复清理路由缓存、导致 DNS 任务中断与域名规则首次加载失败的竞态；真正切换网络设置仍会刷新缓存。

该开关属于网络修复，不随“恢复原有浏览体验”关闭。它不解决反代服务本身停机、失效 API key、登录验证或所有网络均不可达的问题。
