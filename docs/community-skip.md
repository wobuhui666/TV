# 社区片头与片尾时间段

TV 与手机播放设置中的「社区片头片尾跳过」默认开启。影片身份在来源解析播放地址时就开始后台识别，播放开始复用同一查询；时长明确后才查询对应版本的区间。所有网络请求在独立后台线程执行，播放与界面不等待返回，不创建音频探针或额外播放器，不采样、上传媒体或提交标记。没有记录、无法可靠识别影片、服务超时或不可用时，正常播放。

总开关关闭后停止当前查询与跳过；当前播放中重新打开会在下一次进度更新启动查询，无需换集或重播。

## 播放规则

- 保留服务的绝对 `start_ms` / `end_ms`。例如片头在 80–170 秒，只在播放进入该区间时跳到 170 秒，前面的剧情继续播放；片头不受「必须从零开始」或「必须位于前半段」限制。
- 片尾跳到标记结束位置，继续播放后面的彩蛋。服务明确标注延伸至视频末尾时，才跳到末尾，由原播放流程自然结束。
- 每个区间在一次播放会话中只跳一次，回退后可以重看。暂停、进度条拖动、外部播放器跳转、无播放所有权或不可寻址时，不执行跳转。
- 现有手动片头、片尾设置分别优先，包括长按清零。社区时间段不写入这些按长度计算的历史字段，避免覆盖手动设置或沿用到下一集。
- 换集、换源、刷新、出错和退出会取消查询。返回结果须匹配仍然有效的会话以及来源、线路、季集与时长。

## 服务接口

| 顺序 | 只读查询 | 使用标记 |
| --- | --- | --- |
| TheIntroDB | `GET https://api.theintrodb.org/v4/media`，TMDB ID、季集与当前毫秒时长 | `intro[]`、`credits[]` |
| IntroDB | `GET https://api.introdb.app/segments`，IMDb ID、季集；电影使用 `is_movie=true` | `intro`、`outro` |
| TheOtherDB | `POST https://playback.theotherdb.org/api/metadata`，`tmdb_id_tv` / `tmdb_id_movie` | 单个匹配版本的 `marker[]`，秒转为毫秒 |

接口均无需这些服务的账户或令牌。每个服务返回的可用区间立即生效：片头先到即可使用，片尾继续后台补齐，无需等待全部服务完成。后续服务补充前面服务缺失的标记类别，不替换已经可用的片头，也不重置已经跳过的区间。只处理片头及片尾，保留回顾、预告、章节和彩蛋。

TheIntroDB 查询传入 `merge_unknown=false`；返回已知版本时长须与播放时长相符。TheOtherDB 只选择一个相符版本，等距但标记冲突时忽略。IntroDB 没有提供版本时长，使用其绝对位置、置信度和边界检查，不猜测或平移时间。不能保证不同剪辑版本都能匹配。服务没有记录、返回低置信度区间或身份信息不充分时不会自动跳过。播放器里的片头／片尾数字是手动偏好；社区区间不会写入这些数字。结果迟到时，仅在当前进度仍位于区间内才跳到结束位置，已经播放完的片头不会再回跳。

真实源的影片名、年份和类型通过已有 TMDB 路由严格识别，并获取 IMDb ID；需要发布包已有的 `TMDB_API_KEY`。明确的 `tmdb:tv:` / `tmdb:movie:` 标识可直接使用。源只提供「第 N 集」时，单季作品在 TMDB 确认唯一正常季后补齐季号。多季作品只有在当前线路的真实集号完整覆盖 1–N、总数超过每个正常季的集数，且 TMDB 提供唯一、连续、无重复的 Absolute 集数组时，才按官方映射转换为季集；例如《黑色五叶草》的连续第 171 集对应第 2 季第 1 集。倒序展示不影响匹配；缺集、重复号、自动生成的序号、特别篇或不明确的列表不作为连续集数依据。同名歧义、上下集、合并集和预告仍不猜测，普通源缺少密钥或可靠元数据时继续使用手动设置。

默认反代为 `https://t.coolmarket.eu.org/`。社区身份查询可使用该反代的 `X-Tmdb-Query` 与 `X-Title-Normalizer` 响应声明，识别带年份、画质、配音或更新标签的片名；接受的处理来源为 `rules`、`primary`、`groq` 和 `workers-ai`。应用只接受能由原名中明确的附加标签或来源标记解释的清理结果，保留原标题的数字、来源年份及已确认季集；不会接受翻译、随意截短或删除续作编号。声明随对应查询缓存保存，直连官方或未提供有效声明的自定义反代继续严格核验原名。

每次服务查询总预算 6 秒，TMDB 身份查询总预算 8 秒；请求可实际取消。短暂的身份网络失败最多重试一次，线程池忙时从后续进度更新限次重新入队，不占用播放线程等待；无匹配结果不持续重查。首次时长修正较大时取消旧区间并重新核验，仍保留已经跳过的区间状态。元数据保存在有限的内存缓存中，换集不沿用其他集的时间段；失败与空结果短暂缓存，服务限流时暂缓该服务请求。

影片搜索与详情使用设置中选定的 TMDB 路由，超时并不按所在地区判断。反代的搜索接口无响应时，可在 **设置 → 来源 → TMDB 连接方式 → 直连官方** 核对连接；完整说明见 [TMDB 连接设置](native-discovery.md#tmdb-网络兼容)。切换 TMDB 路由不改变三个社区时间段服务的查询地址。
